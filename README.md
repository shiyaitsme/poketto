# Poketto · 口袋工具箱

**Poketto**（ポケット，口袋）是一个收藏小型交互式可视化工具的网站。
不限学科、不限主题：数学、物理、语言、历史、音乐……只要一个小工具能让某个知识点“看得见、摸得着”，就可以放进这个口袋里。

## 理念

- **小**：每个工具只讲清楚一件事，打开就能用。
- **可视化**：用交互和图形代替大段文字。
- **随手积累**：遇到好用的想法，就做成一个小工具收进来。

## 目录结构

```
index.html        首页，列出所有工具
tools/            每个工具一个独立的 HTML 文件
tools.json        工具清单（标题、学科、简介、链接）
assets/           共享设计样式、纸张与笔刷效果、工具脚本
```

## 添加一个新工具

1. 把工具的 HTML 放进 `tools/`，例如 `tools/my-tool.html`。
2. 在 `tools.json` 里加一条记录：

```json
{
  "title": "工具名称",
  "subject": "学科",
  "description": "一句话说明它能做什么",
  "url": "tools/my-tool.html"
}
```

首页会自动读取 `tools.json` 并显示新工具。

## 工具页面设计约定

新增或修改工具时，先对照已有工具，并复用 `assets/poketto.css` 和 `assets/poketto.js`。工具自己的 CSS 只负责布局和专属可视化，字体、颜色和基础控件沿用共享样式。

- 页面使用 `pk-page`、`pk-bar`、`pk-head` 和 `pk-foot`，保持统一的导航、标题星形装饰和返回首页入口。
- 卡片和面板使用 `pk-br` 四角括号边框；需要遮住背景笔刷时叠加 `pk-veil`。
- 滑杆使用 `pk-range`，快捷按钮使用 `pk-chip`（中文加 `zh`），不另写浏览器默认控件样式。
- 「生活里的光」场景卡片只在 hover 时显示淡绿色底色，选中状态用实心圆点及 `aria-pressed` 标识，不保留绿色底色。
- 桌面可视化与控制区分栏，小屏改为单栏；保留键盘焦点样式及控件标签。

## 生活里的光：交互说明

- 天空：拖动或按方向键环顾，太阳高度可调到地平线以下，预设覆盖白天到蓝调时刻。
- 肥皂膜：在「看整个泡泡」中拖动环绕空心球壳，点击表面选点，或用上方、正面、边缘快捷选点；「放大选中处」保留泡泡并展开这块局部水膜的内外界面光路。圆环观察点的膜厚和局部斜视角与下方红、绿、蓝代表波长的归一化强度及波形联动。「绿光更亮／绿光变暗」预设演示增强与抵消，颜色来自全可见光谱的近似积分。
- 池底光纹：可环绕的 3D 水池与俯视池底视角，支持水面动画／暂停、抽样折射光路、水面起伏和水深对照。亮纹来自均匀入射光经过二维水面折射后的池底落点密度；可视光路与亮纹共享同一计算。
- 三维场景使用原生 WebGL，不支持时回退二维示意；光路中的膜厚做了放大。各场景的物理近似见页面「关于这个模型」。

### 模型与验证

天空使用典型情景配色，不作天气预测；泡泡采用局部薄膜两束光干涉近似；池底光纹由折射光线落点密度生成。各场景均在页面内注明近似范围及降级行为。

已验证场景切换、泡泡选点和环绕、局部放大、水池视角、光路显示及动画暂停；数值检查覆盖薄膜增强／抵消、球面取样、斯涅尔定律、平静水面均匀照明及水深对落点的影响。

## 极光：说明与待办

页面：`tools/aurora.html`（单文件，依赖 `assets/poketto.css` 与 `assets/poketto.js`；WebGL 页面请用本地静态服务器打开，不要直接双击）。参考照片：`assets/极光参考图.png`（1638×1112），「照片色」色板的颜色取自它。

### 第一部分：演示

- 渲染：一个全屏片元着色器。光幕是悬在 90 到 330 km 的 3 张薄片，沿视线分 24 层累加亮度；每张片的中心线随经度弯曲、随高度倾斜和扭曲。树在另一张 2D canvas 上，按与天空相同的相机参数逐条投影。
- 交互：拖动环顾（带惯性）、滚轮缩放、悬停时光幕被牵向光标、点击或回车引爆亚暴（波纹沿光幕扩散）、方向键转动视角。
- 滑条：粒子能量（与第二部分共用同一个状态）、太阳风强度、肉眼 ⇄ 相机长曝光。按钮：引爆亚暴、复位视角、保存截图。
- 色板：照片色、物理配色（氮粉紫、氧绿、氧红）、冰蓝、余烬。地面：雪地森林、海面倒影、纯夜空。
- 性能：根据帧时间自动调整渲染分辨率（0.4 到 1.0 倍）。

### 第二部分：原理

- 磁场剖面：偶极磁力线 r = L·cos²λ，落点纬度 cos²λ = 1/L（L = 6 约 66°）。磁层边界、粒子速度和数量都是示意。
- 高度剖面：能量到高度取近似表（0.1 keV 250 km、1 keV 160 km、10 keV 110 km、100 keV 85 km，按对数插值）。颜色分段：粉紫在约 100 km 以下，绿约 100 到 200 km，红约 150 km 以上，为教学用的粗略划分。

### 艺术版：在地球另一端，和极光共振（英文名 Impossible Aurora；`tools/aurora-art.html`）

独立的展示作品，不在 `tools.json` 里。概念：在极光到不了的地方，观众的动作和声音与极光共振；静止则共振停止，光逐渐被遗忘。

- 着色器复制自科普版并改动：加粉紫核心与竖直光柱（`uCore`、`uCoreX`），整体亮度绑定 `life`，压暗天空，加颗粒和更重的暗角。
- `life`（0.07 到 1）：指针移动、点击、麦克风声音提高它，静止时每秒约降 0.065。低于 0.22 时出现第二句话。
- 地平线是叠加 2D canvas 上的抽象山脊，同层有粉色光晕。
- 麦克风：点「声音」才开启，只读音量，不录音不上传；突然的响声触发亚暴。需要 HTTPS 或 localhost。
- 调试：`?test` 冻结时钟，`?test&life=0.3` 指定 life，用于截图。
- 未验证：真机帧率、手机触控、麦克风实际效果、中文字体。
- 未做：摄像头帧差驱动。

## 部署

静态页面可以由 Worker 的 assets 一起发出（见 `wrangler.jsonc`）。`tools/timeline.html` 的「我的事件」在能连上 `/api/timeline` 时存在 KV（绑定 `TIMELINE_KV`，键 `mine`）。

- 浏览公开：谁都可以看内置时间线；GET `/api/timeline` 只读，有数据时也可以看已保存的事件。
- 写入要密钥：PUT `/api/timeline` 和 POST `/api/timeline/unlock` 必须带 Worker Secret `EDIT_PASS`。密钥用 `wrangler secret put EDIT_PASS` 设在 Cloudflare 上，不要写进仓库、页面或配置。
- 没设 secret，或密钥不对，写入都是 401。去掉整站 Access 之后也不会变成谁都能写。
- 页面上点「解锁编辑」，密钥只记在这次浏览里（关掉页面要再解锁）。直接打开本地文件、或接口不可用时，仍只保存在这台设备的浏览器里；那种本机保存不走编辑锁，解锁也不会把它变成写入网站。只发布静态文件（例如 GitHub Pages）而没有这个 Worker 时，也是这种本机保存。

仓库里没有口令，也没有 Cloudflare Access 的现状记录。Access 是否还包着整站，要到 Cloudflare 控制台确认；确认解锁和保存都正常之后，再考虑去掉 Worker 上的 Access。
